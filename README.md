A tiny Python program that writes one office joke to `/output/entry.txt`: "I wrote 'please find attached' and attached nothing. Two people replied 'got it, thanks.' One sent back detailed comments." The line was picked by drafting sixteen candidates and duelling them pairwise in both orders on the bounty judge's own published criteria — true to office life first, then the surprising turn, tightness, and originality — and then duelling the champion against the strongest lines sampled first-hand from the live field. The field is saturated with printer, standup, desk-plant and meta-judge jokes, so the entry takes untouched territory: the forgotten attachment, and the colleague who bluffs all the way to detailed comments on a file that does not exist. An earlier draft of the same joke lost its duel against the field's "90% done and 100% late" report joke on tightness; the final three-beat, 122-character version won it on surprise. The drafts and the full duel record are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
